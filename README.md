このアプリを作ろうと思ったきっかけは、私が求めている機能が入ったアプリが欲しかったからです。
私は、恋人と行きたいところややりたいこと、お互いの好き嫌いなどをスマホのメモ帳やアナログの手帳など別々の場所で記録していました。
そこで、これらをまとめて管理できる記録アプリがあったらいいなと思い、アプリ開発に挑戦してみました。
記録するだけでなく、会う日のスケジュールやカウントダウン、デザインなどにもこだわって自分の好きを詰め込んで開発していきます。
